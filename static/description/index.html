🎯 Sale Order Priority Management

Version: 17.0.1.0.0

Category: Sales / CRM

Author: Muhammad Azeem

📋 Overview

This module adds a priority management system to Odoo sale orders, allowing your sales team to prioritize orders and focus on high-priority deals.

✨ Features

🎚️ Three Priority Levels

Classify orders into:

  • Low - Standard orders
  • Medium - Regular priority (default)
  • High - Urgent orders requiring immediate attention

📍 Smart Positioning

Priority field appears directly below the customer field in the form view, making it immediately visible when viewing or editing orders.

🔍 Quick Filters

Added filters in list view to quickly show:

  • High Priority orders only
  • Medium Priority orders
  • Low Priority orders
  • Group by Priority

🔒 Manager-Only Editing

Only users with Sales Manager role can edit the priority field. Regular salespeople can view but not modify priorities, ensuring consistent prioritization across the team.

📊 Visual Priority Widget

Uses Odoo's built-in priority widget with star icons for intuitive visual representation.

📝 Change Tracking

All priority changes are logged in the chatter, creating an audit trail.

⚠️ High Priority Alert

Automatic warning notification when an order is marked as high priority.

🚀 Installation

  1. Download the module
  2. Upload to your Odoo instance or place in addons/ directory
  3. Update Apps List
  4. Search for "Sale Order Priority Management"
  5. Click Install

💡 Usage

For Sales Managers:

  1. Open any Sale Order
  2. Click the priority stars below the customer field
  3. Select appropriate priority level
  4. Save the order

For Sales Team:

  1. Go to Sales → Orders
  2. Click Filters → High Priority to see urgent orders
  3. Focus on high-priority orders first
  4. Use Group By → Priority to organize your pipeline

🎯 Use Cases

  • VIP Customers: Mark orders from important clients as high priority
  • Urgent Deliveries: Flag rush orders requiring immediate processing
  • Large Deals: Prioritize high-value opportunities
  • Escalated Issues: Mark orders with customer complaints as high priority
  • Seasonal Peaks: Manage workload during busy periods
