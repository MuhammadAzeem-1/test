📋 Overview

This module provides comprehensive weight tracking for sale orders, helping logistics teams identify heavy shipments that require special handling. It automatically calculates total order weight, displays visual warnings, and logs heavy orders daily.

⚠️ Heavy Order Threshold: Orders exceeding 100 kg are automatically flagged as "heavy orders" and require special attention for shipping arrangements.

✨ Key Features

⚖️ Automatic Weight Calculation

Computes total weight by multiplying each product's unit weight by its quantity:

total_weight = Σ (product.weight × quantity)
  • Updates automatically when order lines change
  • Updates when product quantities change
  • Updates when product weights are modified
  • Stored for fast querying and reporting

🚨 Visual Warning Banner

Prominent warning banner appears at the top of the form view when weight exceeds 100 kg:

⚠️ HEAVY ORDER WARNING
This order has a total weight of 127.50 kg, which exceeds the 100 kg threshold.
Special shipping arrangements may be required.

💡 Usage Guide

Setting Up Product Weights:

  1. Go to Sales → Products → Products
  2. Open any product
  3. Go to Inventory tab
  4. Set Weight (kg) field (e.g., 15.50)
  5. Save the product

Viewing Order Weight:

  1. Create or open a sale order
  2. Add products with weight defined
  3. Total Weight field updates automatically
  4. If weight > 100 kg, warning banner appears

Finding Heavy Orders:

  1. Go to Sales → Orders
  2. Click Filters
  3. Select Heavy Orders (>100 kg)
  4. View all orders requiring special handling

Monitoring Daily Reports:

  1. Go to Settings → Technical → Automation → Scheduled Actions
  2. Find "Log Heavy Orders Daily"
  3. Check Next Execution Date (default: daily at 8:00 AM)
  4. View logs at Settings → Technical → Database Structure → Logging
  5. Or check server logs: /var/log/odoo/odoo-server.log

🔧 Technical Details

Computed Fields:

  • total_weight — Float, stored, depends on order lines
  • is_heavy_order — Boolean, stored, True if weight > 100
  • line_weight — Float on order lines, weight per line

Dependencies:

  • @api.depends('order_line.product_id', 'order_line.product_uom_qty', 'order_line.product_id.weight')
  • Triggers recalculation on any related field change

Cron Job Configuration:

  • Interval: 1 day
  • Next Call: Tomorrow at 8:00 AM
  • Active: Yes
  • Number of Calls: -1 (infinite)

Performance:

  • Stored computed fields for fast queries
  • Indexed fields for efficient filtering
  • Optimized dependency tracking
  • Minimal overhead on order save

🎨 Customization Options

Change Weight Threshold:

Edit models/sale_order.py:

order.is_heavy_order = order.total_weight > 150.0 # Change 100 to 150

Add Email Notification:

Modify cron job to send emails:

template = self.env.ref('sale_order_total_weight.email_heavy_order_alert')
template.send_mail(order.id, force_send=True)

Create Dashboard Widget:

Add action to show heavy orders on dashboard:

<menuitem id="menu_heavy_orders" name="Heavy Orders" parent="sale.sale_menu_root"/>

🐛 Troubleshooting

Weight not calculating?

  • Check that products have weight defined
  • Verify product module is installed
  • Force recalculation: Edit order → Save

Warning banner not showing?

  • Clear browser cache
  • Check total_weight > 100
  • Verify view inheritance is loaded

Cron not running?

  • Check scheduled action is active
  • Verify cron worker is running: --max-cron-threads=1
  • Check logs for errors
